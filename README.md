# 📖 Overview

Dialogues Media Admin Portal is a modern full-stack Learning Management & Registration System developed to simplify educational administration through an intuitive and responsive interface.

The application enables organizations to manage student registrations, authentication, invoices, and administrative workflows efficiently while maintaining security, scalability, and ease of use.

---

# 🎯 Project Objective

Educational organizations require digital systems that are:

- Secure
- Fast
- Easy to Manage
- Responsive
- Scalable
- User Friendly

This platform provides a centralized solution for managing registrations, students, invoices, and administrative operations.

# 🚀 Getting Started

## Clone Repository

```bash
git clone https://github.com/tanmayyenpure/DialoguesMedia-Admin-Portal.git
```

```bash
cd DialoguesMedia-Admin-Portal
```

---

# ⚙️ Backend Setup

Install Composer Dependencies

```bash
composer install
```

Configure Database

- Create MySQL Database
- Import SQL File
- Update

```text
backend/db_config.php
```

with your database credentials.

---

# ▶️ Run the Project

Frontend

Open

```text
index.html
```

Backend

Run using

```text
XAMPP
```

or

```text
Apache + PHP
```
